## 검증으로 바뀐 것

1. "각국 정부의 탈스타링크 수요가 MDA의 세계 시장"이라는 처음 가설은 약하다. 캐나다 밖에서 MDA는 주계약자가 된 적이 없고 부품 공급(IRIS² C$100M+ 등)뿐이다.
2. MDA는 사실상 캐나다 정부 재원으로 움직이는 회사다. 2026년 9개월 매출의 70%가 캐나다.
3. 수주잔고 저점은 3Q26이 아니라 1Q26(C$3.69B)이다.
4. 2027년 매출 +40%대는 시장 컨센서스(C$2.84B)와 같다. 시장과 다른 숫자는 아직 없다.
5. 기존 사업 매출은 네 분기째 C$500M 안팎에서 멈췄고 4Q26 가이던스는 전년 대비 감소다.
