# 우주산업 리서치 프로젝트

MDA Space와 우주산업 관련 논의를 세션을 넘어 이어서 쌓는 공간.
작업 규칙은 루트 `CLAUDE.md`, 논의 이력은 `LOG.md`.

## 구조
```
space/
├── README.md            ← 지금 이 파일 (지도 · 현재 뷰 · 열린 질문)
├── LOG.md               ← 세션별 논의 기록 (최신이 위)
├── companies/
│   └── mda-space/
│       ├── overview.md      ← 회사 개요 · 사업 방향성 · 사업부 구조
│       ├── tracking.md      ← 추적 지표 · 촉매 일정 · 리스크 · 열린 질문
│       ├── ir_notes.jsonl   ← 컨콜/IR 자료 1건 = 1줄 (구조화 기록)
│       └── concalls/
│           └── 2026-Q3.md   ← 분기별 컨콜 정리
└── industry/
    └── themes.md        ← 산업 단위 논점 (LEO 위성망·국방 주권·EO 데이터·발사 등)
```

- 발사 수단 병목(Falcon 9 의존) 이 위성 제조사 일정에 주는 리스크
