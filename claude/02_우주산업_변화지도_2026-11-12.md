## 3. 변화별로 「돈이 어디로 떨어지나」(연결 사슬)

### 변화 1·2 — 로켓 부족과 스타십
```
아마존·원웹·각국 군의 위성 대기 ─▶ 비 SpaceX 발사 좌석 부족 ─▶ 발사 단가 인상·선수금
                                                         ├▶ Rocket Lab(뉴트론 16회 수주, 기본가 7,000만 달러) — 단 첫 비행 2027 이후
                                                         ├▶ Firefly(수주잔고 17억 달러)
                                                         └▶ 엔진·소재: Blue Origin BE-4, 스피어·에이치브이엠(SpaceX 엔진 합금)
스타십 정례화 ─▶ 부족은 풀리지만 「SpaceX 로 더 쏠림」 ─▶ SpaceX 에 파는 소재·부품사만 물량이 는다(추론)
```
- 두 변화는 서로 반대 방향으로 당긴다. **스타십이 빨리 되면** 경쟁 로켓의 값 인상 논리가 약해지고, **늦어지면** 부족이 길어진다. 어느 쪽이든 「SpaceX 엔진 소재」는 물량이 는다(추론).

### 변화 3·4 — 국방 군집과 상업 영상 구매
```
골든돔·SDA·각국 군 ─▶ 위성 수백 기 발주 ─▶ 프라임(L3Harris·Lockheed·Northrop·Rocket Lab·York)
                                        └▶ 병목 부품: 레이저 단말·적외선 센서·태양전지
군·정보기관의 영상 구매 ─▶ 영상 운영자 수주잔고 ─▶ BlackSky·Planet·ICEYE·Synspective / 국내 쎄트렉아이(위성 수출)·한화시스템(SAR 군집)
```
- 위험: 요격체 층은 비용 때문에 빠질 수 있다(S011). York 처럼 계약 방식이 바뀌면 가이던스가 꺾인다(S527).

### 변화 5·7 — 주파수와 위성 인터넷
```
스타링크 가입자 급증(+ARPU 하락) ─▶ 단말 주 20만 대 자체 생산 ─▶ 단말 칩(STMicro: 2025년 약 6억 → 2026년 약 10억 달러 회사 주장)
                               └▶ GEO 가입자 이탈 ─▶ Hughes 파산보호 ─▶ 채권자 Gilat 대손
휴대폰 직접 연결 ─▶ 주파수가 병목 ─▶ 주파수 보유사 인수(EchoStar·Globalstar·Iridium)
비 SpaceX 진영(원웹·아마존·군) ─▶ 외부 단말·게이트웨이 ─▶ 인텔리안테크·Kratos — 단 위성 배치가 늦으면 같이 밀린다
```

## 4. 이 변화 지도로 걸러지는 것

- **이미 발표된 이벤트**(Globalstar·Iridium 인수)는 변화가 가격에 들어갔다 — 롱리스트에서 뺀다.
- **매출이 0 인 이야기**(상업 정거장·궤도 데이터센터)는 C4(증명)에서 막힌다 — 수혜 부품 쪽으로 돌린다.
- **「SpaceX 가 사 오는 것」** 과 **「SpaceX 가 안 하는 것」** 이 두 갈래의 연결이다. 앞은 소재(스피어·에이치브이엠)와 칩(STMicro), 뒤는 국방 데이터·국방 군집·비 SpaceX 단말.
- **부정적 변화도 변화다**: 위성방송, GEO 단말, 계약 방식이 바뀐 국방 프라임은 숏 스크리닝(`smic-short-screening`) 후보가 될 수 있다.
