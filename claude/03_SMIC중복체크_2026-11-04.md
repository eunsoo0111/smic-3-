# 03. SMIC 중복 체크: 미실행 (커버리지 엑셀 없음)

- 저장소와 작업 환경에서 `SMIC Coverage List *.xlsx`를 찾지 못했다. **이 단계는 아직 통과하지 못한 상태**다.
- 최종 후보(BLSH, COIN)는 해외 종목이라 SMIC 과거 커버 확률이 높지는 않다고 본다(추론). 그래도 확인 전까지 "SMIC 신선도" 칸은 **미확인**으로 둔다.

## 엑셀을 받으면 바로 돌릴 코드

```python
import openpyxl, datetime
PATH = "SMIC Coverage List.xlsx"
KEYWORDS = ["Bullish", "불리시", "Coinbase", "코인베이스", "Strategy", "MicroStrategy", "마이크로스트래티지",
            "Robinhood", "로빈후드", "CME", "BitGo", "SBI", "Monex", "Coincheck", "Equiniti", "Computershare"]
ws = openpyxl.load_workbook(PATH, data_only=True)['SMIC Coverage List']
for r in ws.iter_rows(min_row=2, values_only=True):
    if r[1] and any(str(r[1]).startswith(k) for k in KEYWORDS):
        d = r[3].date() if isinstance(r[3], datetime.datetime) else r[3]
        print(r[1], r[2], d, r[4], r[5])
```

## 판정 기준 (스킬 규칙)
- 2년 이내 커버: 피한다. 2~4년: 논지가 다르다는 걸 설명해야 한다. 미래 날짜 행(같은 시기 커버 예정): 피한다.
- 정확한 종목명으로 재확인한다(MicroStrategy → Strategy 사명 변경, 부분 일치 오탐 주의).
- 3팀 과거 보고서 중 크립토·거래소·토큰화 논리와 겹치거나 이어지는 것이 있는지 같이 본다.
