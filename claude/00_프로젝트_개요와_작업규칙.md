# 프로젝트 개요와 작업 규칙 (SMIC 3팀)

## 작업 규칙

### 괴리(C3) 확인 — 해외 상장사
- **해외 종목은 셀사이드 리포트 원문 없이도 괴리를 확인한다.** (2026-11-07 은수 지시)
- 쓰는 근거:
  1. **컨센서스 역산**: 매출·EPS 컨센(stockanalysis/S&P Global 등)에서 내재 성장률·영업이익률·세율을 거꾸로 계산한다. "시장이 2027년에 마진을 몇 %로 놓았나"를 숫자로 보인다.
  2. **실적 콜 Q&A**: 애널리스트 질문이 곧 시장의 관심사이자 걱정이다. 무엇을 묻고 무엇을 묻지 않았는지 정리한다.
  3. **서프라이즈 이력**: 분기별 컨센 대비 실제치. 반복적으로 틀리는 방향이 있으면 시장의 체계적 오류다.
  4. **목표가·레이팅 분포와 변화**, 실적 직후 주가 반응.
  5. 필요하면 현재 주가에서 역DCF로 내재 기대치를 구한다.
- 리포트 원문을 구하면 보강용으로 쓴다. 없다고 판정을 보류하지 않는다.

### 문서
- 단계마다 `claude/NN_제목_YYYY-MM-DD.md`로 남긴다. 기준일, 출처 태그([공시] [콜] [기사] [은수], (추정) (추론) (가정)), 데이터 충돌 표를 넣는다.
- BM 설명은 쉽게, 하지만 숫자는 원문 기준으로.
