# software_stack V0 차이표 (무하네스 초안 ↔ 검색 보강)

레포에 `core/valuechain/*.yaml`이 없어 "레포 보강"은 웹 검색으로 대신했다. 이 체인은 물리적 제품이 아니라 지출 범주 트리로 변형 적용했다(수량·단가 축은 `없음`).

| 구분 | 칸 | 내용 |
|---|---|---|
| 무하네스에만 있던 것 | 전부 유지 | 33노드(입력 25). 삭제한 칸 없음 |
| 검색으로 추가 | `stack.sec.nhi` | 비인간(에이전트) 신원. SailPoint에서 신원 증가분의 40%가 비인간 신원 |
| 검색으로 추가 | `stack.vert.commerce` | 커머스+결제. Shopify가 GMV·결제 침투율로 과금해 좌석과 무관 |
| 검색으로 추가 | `stack.agent.credits` | 좌석 위에 AI 크레딧을 얹는 하이브리드 과금(Figma, monday.com, Atlassian) |
| 검색으로 추가 | `stack.agent.deploy` | AI 배치 인력. ServiceNow가 대형 AI 계약에서 구독 매출 일부가 전문 서비스로 이동한다고 밝힘 |
| 검색으로 내용이 바뀐 칸 | `stack.infra.obs` | Datadog 10-Q가 최대 고객 사용량 감소를 경고. 사용량 과금 인프라는 AI 워크로드에 묶여 있을 수 있다 |
| 검증 못 한 "없음" 행 | `stack.agent.seat` · `stack.onprem` | 모델 지식으로 둔 구조적 부재. 원천 확인 필요 |
