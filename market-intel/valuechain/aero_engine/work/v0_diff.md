# aero_engine V0 차이표 (무하네스 초안 ↔ 검색 보강)

레포에 `core/valuechain/*.yaml`이 없어 "레포 보강"은 웹 검색으로 대신했다.

| 구분 | 칸 | 내용 |
|---|---|---|
| 무하네스에만 있던 것 | 전부 유지 | 26노드(입력 20). 삭제한 칸 없음 |
| 검색으로 추가 | `sv.exec.slot_new` | 신형 엔진(LEAP·GTF) 정비는 OEM 네트워크에 묶여 구형과 다른 칸이다. LEAP Shop Visit 연 25% 성장 전망 |
| 검색으로 추가 | `sv.alt.power` | FTAI Power: 퇴역 CFM56 코어를 데이터센터 발전 터빈으로 전환. 초안에는 "항공 밖 경쟁 용도"라는 단계 자체가 없었다 |
| 검색으로 추가 | `sv.alt.igt` | 발전용 가스터빈이 같은 주조 라인·초합금 용해로를 쓴다. AI 독립성 판정에 필요 |
| 검색으로 내용이 바뀐 칸 | `sv.mat.cast` | GE가 주조사 CPP를 117.5억 달러에 인수 합의(2026-09-08). 초안은 주조를 독립 과점으로만 봤다 |
| 검색으로 내용이 바뀐 칸 | `sv.parts.pma` · `sv.parts.hpt` | 초안은 "고온부 PMA는 드묾"이라 적었으나, Chromalloy가 2025년 10월 CFM56 HPT 블레이드 PMA 승인을 받았다 |
| 검증 못 한 "없음" 행 | `sv.parts.pma_llp` · `sv.parts.usm_new` | 모델 지식으로 둔 구조적 부재. 원천 확인 필요 |
