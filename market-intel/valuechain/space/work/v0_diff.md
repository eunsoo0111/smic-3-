# V0 차이표 — 무하네스판(v0_blind) vs 레포 보강판(v0_tree)

- 기준일 2026-11-12. 레포에는 `README.md` 한 개뿐이었다(체인 yaml·라이브러리·기존 스터디 없음).
- 따라서 **두 판은 동일**하다. 무하네스에만 있던 것 0 · 레포에만 있던 것 0.
- V0 초안은 본체가 직접 썼다(`build_v0.py`). 스킬 표준은 vc-decomposer 서브 → 본체 승인이지만, 레포가 비어 「레포에 끌려가는 편향」이 생길 수 없어 서브를 생략했다. 초안자 = 승인자이므로 구조 누락은 사용자가 한 번 봐야 한다.
