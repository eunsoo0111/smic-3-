# 판단 규칙 모음 — 서브 프롬프트에 인용하는 「데이터 얻는 법·가공법·판단법·답변 정제」 (인텔리전스 4분류를 우리 규칙으로)

## ① 데이터 얻는 법
- DART 는 1차 원천, 스크래퍼·셀사이드는 보조. 공시 유형: 신규시설투자·잠정실적·IR 은 I(거래소공시) — B·E 만 검색해 「공시 0」 쓰지 않는다.
- DART 호출 ≤30/분, 전수 스캔은 제목 목록만·원문은 표본(과다 호출 차단 사고). 관세청 1년 창·≤60/분·국가행 합, empty = 빈 성공(0 아님).
- 회사 IR 덱은 회사 사이트에서(DART IR 통지 93건 중 덱 첨부 0), 회사 전망은 「회사 주장」, 어조 한 단계 낮춰 읽기.
- 없다 주장 전 질의 커버리지(기간·유형·키워드)를 적는다.

## ② 데이터 가공법
- 물량축·금액축 분리(현지 생산 전환 = 수출 감소 오독 금지). 반기 누계 vs 분기 차분을 칸마다 적는다. 리스 회계(IFRS16 vs JGAAP/US GAAP 운영리스) 다르면 P/E·EV/EBIT 로. 기준 변경(K-IFRS 1118 영업이익)은 두 기준 병기.
- 단위(천원/백만원/억원)·통화·환율 시점 명기. 조정 EBITDA 가 사용권 상각을 되더하는지 확인. 세그먼트가 로열티 전/후인지.
- 시계열은 tam·demand·supply·q·asp·share 여섯 축, 점마다 {t,v,grade,source}. 수정주가 vs 원주가 혼합 금지.

## ③ 데이터 판단법
- 내러티브 먼저: 시장이 믿는 이야기 → 우리 가설 → 검증. 이해 없이 계수만 쌓지 않는다.
- 드라이버는 EPS 를 움직이는 것과 배수를 움직이는 것으로 나눈다(예: 기존 시장 = EPS, 신시장 = 배수). 배수는 믹스가 아니라 같은 성장 국면 창의 중앙값.
- 이미 나온 이벤트는 반영됐다 — 기대는 앞으로 나올 것만. 기대는 6~12개월 뒤 좋아질 것. 「우위 없으면 0」.
- 커버리지 낮은 원장에서 결손을 세면 그건 우리 진도다. 일치는 독립이 아니다. 올라간 수치는 더 검산.
- 관문은 증상을 본다·막아야 한다. 문턱은 데이터 전에 쓰고 맞추려 고치지 않는다(정정은 「문턱 정정」으로 표기).

## ④ 답변 정제
- 두괄식: 콜·크기·기대 vs 시장·판정일 한 표 → 내러티브 → 종목 드라이버 → 기대 표 → 아이디어 조건 → 근거 장. 단서는 각주.
- 빈칸 = 값 / 없음—이유 / 미측정—누가·언제. 등급 ①②③ 병기. 숫자 옆 출처·asof.
- 노션 게시는 파일→정규화 diff 검증. 개인 식별 정보·리뷰 본문·키 값 금지.
- 회사마다 고유 틀(축은 그 회사의 변수), 참조 양식 과적합 금지.
