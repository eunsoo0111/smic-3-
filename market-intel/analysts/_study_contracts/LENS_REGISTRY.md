# 기업별 렌즈 등록부 — 「무엇을 봐야 하나」가 추적 데이터를 정한다 

규칙: 렌즈 한 줄 → 참이어야 하는 것 → 추적 데이터(원천·주기) → 배선(core/series/registry.yaml 등재 ✓/✗). 배선 ✗ 는 수집기 의무.

| 종목 | 렌즈(무엇을 보나) | 참이어야 하는 것 | 추적 데이터(원천·주기) | 배선 |
|---|---|---|---|---|
| 예시 000000(가상 종목) | **원가 축**(주원료 가격) | 원료 가격 하락이 마진으로 전이되고 판가는 유지된다 | 원료 국제가격(일)·관세청 HS 수입단가(월)·소비자물가 해당 품목(월) | 원료가 ✓ · 관세청 HS ✗ |

행은 각자 커버리지 종목마다 하나씩 쓴다(위 행은 형식 견본이지 실제 종목·투자 의견이 아니다). 다음: 배선 ✗ 열의 원천을 `core/series/registry.yaml` 에 등재하고 수집 레인을 예약 실행에 넣는다 — 종목 스터디 S1.5 의 의무.

## 판정 기준 — `tools/study/lens_watch.py`
| 색 | 조건 | 뜻·다음 행동 |
|---|---|---|
| 🔴 테제 문턱 | 모델이 이미 계산한 경계에 닿음 **그리고** basis(모델 json 경로·검증 파일)가 있음 | must_be_true 가 깨졌을 수 있다 → study-tracker 재판정, changelog 에 그 지표 id 로 판정 행(kept/changed) → 그 뒤 「판정 완료」로 다시 안 울림 |
| 🟠 근거 없는 문턱 | 문턱에 닿았지만 basis 없음 | 사람이 고른 숫자라 재판정 근거가 못 된다 → 모델 민감도에서 문턱을 다시 산출할 것 |
| 🟠 이상 움직임 | 최신 변화의 \|z\| ≥ 2.5(일간 = 일 변화, 월·분기 = 전년 동기 변화율, 과거 3년 분포) | 문턱 없이 모든 지표에 자동 — 「왜 움직였나」 확인 |
| 🟠 노화 | 마지막 값이 주기별 기한 초과(d 5·w 10·m 45·q 120일) | 수집 레인 점검 |
| ⚪ 배선 없음 | 시계열 미등재 | 수집기 의무 |

**문턱 값은 손으로 고르지 않는다** — ① 모델 스트레스 입력 ② 진입·청산 손익분기 ③ 케이스 경계 ④ must_be_true 의 숫자 중 하나에서 가져와 basis 칸에 경로(모델 json·검증 파일)를 적는다. 모델 민감도가 아직 없는 지표는 🟠 까지만 울린다(다음: 민감도 연결).
